\subsection{Objetivos Específicos}

\begin{itemize}
	\item Identificar y agrupar los datos de las pruebas Saber 11 y Saber Pro de los estudiantes, para establecer una base comparativa de las competencias individuales y grupales.
	
	\item Analizar la relación entre las competencias iniciales en Saber 11 y los resultados finales en Saber Pro, empleando estimadores y modelos de correlación.
	
	\item Desarrollar un modelo predictivo para estimar la evolución de las competencias académicas vistas desde el Saber 11 hasta el Saber Pro aplicando modelos estadísticos.
	
	\item Integrar un módulo auditor que verifique el estado y funcionamiento del Software y actúe como mecanismo de supervisión y mantenimiento.
	
\end{itemize}
